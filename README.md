# IEEE RPG Inventory Engine

## Description

A Python-based RPG Inventory Engine for managing game items,
player inventory, and equipment using Object-Oriented Programming
(OOP) and advanced data structures.

## Features

- Add and manage inventory items
- View player inventory
- Search and manage items
- Organize game items using Python data structures
- Handle invalid inputs using exception handling
- Read and process data from external files

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Lists
- Dictionaries
- Sets
- Tuples
- File Handling
- Error and Exception Handling
- List and Dictionary Comprehensions

## Data Source

All project data is stored in an external file and loaded into
Python. Data is not hardcoded directly inside the Python program.
